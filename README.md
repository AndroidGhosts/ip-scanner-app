# IP Scanner App 📡

تطبيق أندرويد لفحص نطاقات IP عبر البورت 80

## الميزات
- فحص نطاقات IP
- كشف المضيفين النشطين على البورت 80
- واجهة مستخدم بسيطة
- حفظ النتائج

## التثبيت
1. حمل ملف APK من قسم Releases
2. ثبّت التطبيق على جهازك
3. امنح التطبيق صلاحية الإنترنت

## الاستخدام
1. أدخل نطاق IP (مثال: 192.168.1.0/24)
2. انقر على "بدء الفحص"
3. انتظر ظهور النتائج
